QR Code Generator

A simple web-based QR Code Generator built with HTML, CSS, and JavaScript. This tool allows you to create QR codes for text or URLs instantly using the QR Server API.

 Features
- Generate QR codes for any text or URL.
- Simple, clean, and responsive design.
- Displays QR code immediately after input.
- Hides QR code if input is empty.
- Lightweight and easy to use.

How to Use
1. Clone or download the repository.
2. Open `index.html` in your web browser.
3. Enter the text or URL in the input box.
4. Click **Generate QR Code**.
5. Scan the generated QR code using your mobile device.

Technologies Used
- HTML
- CSS
- JavaScript
- QR Server API
